# M5b 计划 —— 装备品质机制

## 这一版做什么

给装备加 **白 / 绿 / 蓝 / 紫** 四档品质。品质是**每件掉落物各自摇出来的**（不是写死在物品表里的），
所以 6 件基础装备就能变出 4 倍花样 —— 这是之后「60 件装备」能省一大半数据量的地基。

1. **Domain 新概念**
   - `ItemQuality` 枚举（White / Green / Blue / Purple）
   - `ItemQualityRules`：价格倍率、属性倍率、显示名、解析
   - `LootTuning`：品质权重 + 「怪越高级越容易出好货」的成长系数
2. **品质摇在掉落那一刻**
   - `DropRoller.Roll` 多摇一次品质；只有装备才摇，药水/材料恒为白
   - `ItemDropResult` / `Entity` / `ItemInstance` 三层都带上品质
   - 物品表可以写 `minQuality` 把某件装备兜到「至少绿」
3. **品质真的有用**
   - 属性：`StatCalculator` 按品质倍率放大装备加成（1.0 / 1.25 / 1.55 / 1.9）
   - 价格：买入价 = 基础价 × 品质倍率（1.0 / 1.6 / 2.6 / 4.2），卖出价 = 买入价 × 回收系数
   - 面板 / 商店 / 地面名字 / 拾取飘字 全部按品质上色，鼠标提示写明品质
4. **存档带上品质**（`SaveData` 升到 v2，v1 旧档读进来全部当白色，不丢东西）
5. **数据自检**：品质权重、属性倍率单调、掉落物品质合法性、商店不出售蓝紫

## 这一版**不做**（留给下一步，别顺手夹带）

- ❌ 铺 60 件装备（那一步只是往 `items.json` 填数据，机制已经在这版打好）
- ❌ 铺 15~20 种怪
- ❌ NPC 传送员
- ❌ 品质对**掉落几率**的影响（比如「紫装只在洞窟掉」）—— 这版只做「怪越高级越容易出好货」的通用曲线
- ❌ 附魔 / 洗练 / 词条 / 强化 —— 品质只是倍率，不做随机词条
- ❌ 换图标美术（品质只改颜色和边框，不动 `PlaceholderArt` 的图）
- ❌ 商人出售蓝紫装（当前规则是**商店只卖白绿**，好东西靠打）

## 验收

- `bash Tools/run-all-checks.sh` 全绿（无头 Domain 自检 + 四层编译检查）
- Unity 菜单 ④ 冒烟自检全绿（含新的 items 数据校验）
- 肉眼可验：打死怪掉的装备名字有颜色；穿上紫装攻击力明显高于白装；卖紫装明显更值钱；
  F5 存 / F9 读之后背包里的紫装还是紫装
