# P0 计划 —— 挂机核心（页游爽感第一周）

> 对应 `docs/优化建议清单.md` 的 P0 七条。目标：**做完这版，开着挂机挂通宵，回来看收获**。

## 先交代两个核实结果（影响设计）

1. **玩家操作全部走 `_intents`**（`GameBootstrap` 里 `_input` → intents），
   所以自动战斗 = 一个"没被手操占用时往列表里写意图"的组件，**Domain 一行不碰**。
2. **升级已经回满血**（`DeathSystem` 里注释写明），所以"升级爆发"只剩：回蓝 + 全屏闪 + 大字 + 更大的环。

## 做什么（七条，按依赖排序）

### #1 自动战斗 `AutoPilot` —— 成本：中 · 地基

- `T` 开关；HUD 显示"挂机中"状态
- 每 tick 产出意图：选目标（切比雪夫 ≤ 12 格内最近的活怪）→ 用 `PathFinder` 走一步 →
  进入射程按攻击间隔普攻 → 技能 1 冷却好且 MP 够就放
- **手操优先**：这一 tick 你按了移动/攻击/技能，挂机就全部让位
- 安全阀：HP 低于紧急阈值（30%）时只走位不攻击（配合 #2 自动喝药）
- 没怪可打：原地待机（不做跨图巡逻——那是以后的事，先别让它走进怪堆送死）

### #2 自动喝药 —— 成本：小

- Domain 加纯函数 `ItemSystem.FindPotion(who, catalog, mana)`：背包里**最便宜的**那瓶血/蓝药
- Unity 侧检测 `Hp/MaxHp < 阈值` → 队列 `UseItem` 意图（走现有 `ItemSystem.Use` 通道）
- 阈值进 `CombatTuning`（`AutoPotionHpPct=0.5` / `AutoPotionMpPct=0.3`，带 Clamp）→ **F1 面板可调**
- 防连灌：两次喝药至少间隔 20 tick（挂机不心疼药，但要给"药快见底"一点张力）

### #5 升级爆发 —— 成本：小

- Domain：升级时 `Mp = MaxMp`（血已回满）
- 表现：全屏白闪 0.15s + "LEVEL UP!" 居中大字 + 升级环加大一档

### #3 战力值 —— 成本：小

- Domain 纯函数 `StatCalculator.CombatPower(e)` = 攻中值×3 + 防×2 + 血×0.5
- 角色面板顶部大字；变高时头顶飘 `战力 +N`

### #6 掉落通知流 —— 成本：小

- 屏幕右下角通知流（最多 5 条，旧的淡出）：蓝装起推送，紫装变紫；金币连捡合并"金币 +N"
- 白绿不推——挂机一晚全是白装通知就是噪音灾难

### #4 收益统计面板 —— 成本：小

- 挂机开启时显示：时长 / 击杀 / 经验 / 金币 / 装备按品质计数 + 效率行（击杀/分钟）
- 数据在 Unity 层订阅事件累计；**存档持久化放到 P1**（这版先做"本次挂机统计"）

### #7 离线收益 —— 成本：中

- 读档时按 `SavedAt` 算离线时长（封顶 8h），按玩家等级带内**非精英怪的平均效率**折算经验金币
  （同一套口径：怪表 exp/kill ÷ 审计 TTK 口径，别另写公式）
- 另摇 3 件当前等级段装备（复用 `DropRoller` 的品质摇号，品质封顶蓝——离线不白给紫）
- 上线弹"欢迎回来"结算面板；背包满则少给（不塞爆）

## 不做（明确排除）

- ❌ 跨图自动巡逻 / 自动回城卖货（挂机 AI 先只守一张图）
- ❌ 收益统计写进存档（P1 随耐久一起进 `Version3`）
- ❌ 自动修装备（耐久本身还没做，那是 P1-8 的前置）
- ❌ 任何 Domain 结构性改动（本版只加纯函数与调参字段）

## 验收

- `bash Tools/run-all-checks.sh` 全绿；四层编译 0 error
- Unity 批处理 302+ 项全过、失败项 0
- 新增自检：自动喝药按阈值触发且选最便宜的、防连灌；战力值计算与权重一致；
  通知流只推蓝以上且上限 5 条；离线收益封顶 8h、品质封顶蓝、不塞爆背包
- 肉眼可验：`T` 开挂机 → 角色自己打怪捡东西；血掉一半自动灌药；升级全屏闪+回满；
  右下角蓝紫装通知滚滚来；读档弹"欢迎回来"
