# M5c 计划 —— 铺 60 件装备

## 这一版做什么

把 `items.json` 的装备从 13 件铺到 **60 件**，全部走已经做完的装备品质机制。
因为 60 件手写 JSON 一定会写出前后矛盾的数值（同一部位越高级越弱、价格倒挂、掉落表引用错 id），
所以**用脚本生成 + 脚本校验**，和 `Tools/gen_maps.py` 一个路子。

### 三条设计轴

1. **部位 × 等级段**：8 个部位（武器/衣服/头盔/项链/手镯/戒指/腰带/靴子）× 3 个等级段
   （Lv1 / Lv4 / Lv7 —— 正好对上现有的鸡(1)/野狼(4)/野猪(6)，每件装备都有怪能出）
2. **同段内 2~3 个档次**：基础款（品质下限白）/ 上品款（下限绿）/ 珍品款（下限蓝）。
   档次越高**白装基础属性就越高**，不是靠摇品质才变强 —— 这样「品质阶梯不倒挂」是数据保证的，不是运气
3. **强度/价格走同一条曲线**：`P = f(等级) × 档次倍率`，各部位按固定权重把 P 拆成 minDc/maxDc/ac/bonusHp/bonusMp

### 具体交付

- `Tools/gen_items.py`：设计表 -> 生成 `items.json`，同时把 MapLoader / ItemCatalog 的解析规则和
  Domain 的硬约束各实现一遍（不带 `--write` 只校验并打印，和 `gen_maps.py` 一致）
- `items.json`：60 件装备（消耗品 / 材料原样保留）
- `monsters.json`：三只怪的掉落表接上对应等级段的装备，每件装备至少一个出处
- `npcs.json`：货架扩到白装 + 精良货（**不出售稀有/史诗**，自检守着）
- 自检新增：部位断档、同段属性/价格单调、品质阶梯不倒挂、每件有出处、掉落的怪等级与装备等级对得上
- 顺手补一条一致性：**商店按物品表的 minQuality 卖**（买精良下限的货，拿到的就是精良，价格也按精良算），
  否则会出现「物品表说这件最低是精良，商店却卖白板」这种自相矛盾

## 这一版**不做**（留给下一步）

- ❌ 加新怪、改怪的等级、按地图分等级带（那是「铺 15~20 种怪」那一块）
- ❌ NPC 传送员
- ❌ 改品质倍率（1.0/1.25/1.55/1.9 与 1.0/1.6/2.6/4.2 保持不变）
- ❌ 词条 / 强化 / 洗练 / 附魔
- ❌ 新美术：新装备不写 `sprite` 字段，`SpriteId` 自动落成 item id，
  `PlaceholderArt` 按 key 取色 —— 所以每件颜色不同、形状还是那个占位菱形。真正接素材留给「换美术」那一步

## 验收

- `bash Tools/run-all-checks.sh` 全绿（无头 Domain 自检 + 四层编译）
- `python3 Tools/gen_items.py` 校验通过（默认不落盘）
- Unity 菜单 ④ 冒烟自检全绿（含新的 items 数据校验）
- 肉眼可验：鸡/狼/猪掉的装备等级段明显不同；同一段里珍品款明显强于基础款；商店里精良货显示为绿字且更贵
