# M6b 计划 —— 战斗特效

## 这一版做什么

补上"打起来看不见"的那几处。现在只有**普攻刀光**和**飘字**，命中、暴击、死亡、升级、爆装都没有画面上的"那一口"。

全部**代码画**（`PlaceholderArt` 运行时生成 Sprite），和现有刀光/占位图一套风格，**不引入任何美术素材**。

### 交付

| 特效 | 触发 | 长什么样 |
| --- | --- | --- |
| 命中爆点 | `DamageDealt`（非暴击） | 目标身上一个小白蓝星芒，0.16 秒炸开淡出 |
| 暴击爆点 | `DamageDealt`（Crit） | 更大更暖的金橙色 + 一圈冲击波环 + **轻微镜头震动** |
| 挨打闪红环 | `DamageDealt` 打在玩家身上 | 红色环 + 镜头震动（比暴击轻） |
| 死亡烟尘 | `EntityDied`（怪） | 灰褐色烟团，边升边淡 |
| 玩家死亡 | `EntityDied`（玩家） | 暗红色大烟团 + 更重的震动 |
| 升级光柱 | `LevelUp` | 金色光柱从脚下升起 + 扩散环 |
| 复活光柱 | `PlayerRespawned` | 蓝色光柱 |
| 技能特效 | `SkillCast` | 攻杀剑术 = 更大的斩击；刺杀剑术 = 身前两格的直线斩；烈火剑法 = 自身周围扩散环 |
| **掉落光柱** | 地面掉落物品质 ≥ 蓝 | 品质色光柱**一直立在**掉落物上，直到被捡走 —— 传奇里"看光柱就知道爆了什么" |

### 做法

- `PlaceholderArt` 新增 5 种程序化图形：星芒爆点 / 扩散环 / 烟团 / 光柱 / 直线斩
- `CombatFxPool` 从"只会放刀光"扩成一个**通用的特效池**（主层 + 附加层，按种类走不同的缩放/上浮/旋转/淡出曲线）
- `CameraRig` 加**镜头震动**：平滑位置和抖动偏移分开存，抖动衰减回 0 —— 不能把抖动喂回平滑，否则相机会漂
- 掉落光柱做成**覆盖层**而不是池里的特效：它是"跟着掉落物存在"的，不是一次性的，
  和 `LootLabelOverlay` 一样每帧扫一遍地面掉落物就行，不用管生命周期

## 这一版**不做**

- ❌ 音效相关（M6a 已完成，不回头改）
- ❌ UI 皮肤、数值平衡、手感调参面板
- ❌ 换美术素材（地表/角色仍是代码画的占位图）—— 这是独立的一块
- ❌ 粒子系统 / Shader / 后处理：继续用"运行时生成 Sprite + 代码动画"，零资源、无 Shader 依赖
- ❌ 屏幕外的特效（远处不画，省下来）

## 验收

- `bash Tools/run-all-checks.sh` 全绿（Domain 一层不会被碰，只加表现层）
- Unity 菜单 ④ 冒烟自检全绿（含特效池的池化复用 / 换图清空 / 光柱只给蓝紫 / 震动会衰减回 0）
- 肉眼可验：打怪有爆点、暴击更大还有震动、怪死有烟、升级有金色光柱、
  爆出蓝紫装时地上立着光柱、放技能三种特效各不一样
