# M5d 计划 —— 铺 15~20 种怪

## 这一版做什么

把怪从 3 种铺到 **20 种**，按等级带分到两张战斗图（草原 / 洞窟），让「越往深处越强」这条曲线立起来。

### 三块

1. **20 种怪的名单**：Lv1 ~ Lv15，草原放 Lv1~6，洞窟放 Lv3~15（入口浅、深处强）
2. **两种新 AI（都很小，是"不同 AI"那部分）**
   - **远程怪**：`attackRange` 在数据里就能调（AI 和战斗本来就认这个字段），但**得能看见才出手** ——
     加一条视线判定，否则会隔着石墙射你
   - **群居怪**：新字段 `packRadius`。打了狼群里的任何一只，半径内的同类一起扑上来
3. **掉落表 + 刷怪区**
   - 每只怪一套掉落表（按等级带引用 M5c 那 60 件装备），每件装备仍然都打得到
   - 草原 / 洞窟的刷怪区重排成难度带：草原西北最安全，洞窟从入口往深处逐级加码

### 等级带怎么定（不用新加机制）

和 M5c 同一条规则，纯由怪的等级推出来：

| 怪的等级 | 掉的装备段 | 装备需求等级 |
| --- | --- | --- |
| Lv1~3 | b1 | Lv1 |
| Lv4~6 | b2 | Lv4 |
| Lv7+ | b3 | Lv7 |

**注意**：装备目前只铺到 Lv7，所以 Lv8~15 的怪掉的是"当前最好的那批"（b3）。
把装备继续往上铺是下一步的事，这一版不夹带 —— 但规则已经就位，加一段数据就能接上。

### 交付

- `Tools/gen_monsters.py`：怪名单 + 掉落表 + 刷怪区校验，生成 `monsters.json`
  （掉落表按 `band_for_level` 从 `gen_items.py` 的设计表里取，两个脚本不重复定义规则）
- `Tools/gen_items.py` 收敛为「只写 items.json、只校验 monsters.json」，不再写怪物文件
- `Tools/gen_maps.py`：洞窟的刷怪区改成难度带
- 代码：`LineOfSight`（视线）、`CombatSystem.AlertPack`（群居惊动）、`Entity/DTO.packRadius`
- 自检新增：视线不穿墙、群居惊动只惊动同类且在半径内、每只怪至少被一个刷怪区引用、
  两张图的难度分层（草原最高怪 ≤ Lv6，洞窟最高 ≥ Lv10）

## 这一版**不做**（留给下一步）

- ❌ 把装备从 60 件往上铺到 Lv10+（M5c 刚做完，再动就是重开那一块）
- ❌ NPC 传送员（M5 的最后一块）
- ❌ 法术投射物 / 召唤 / 施毒（那是法师道士那块，明确暂缓）
- ❌ BOSS 的专属机制（狂暴、分身、阶段转换）—— 这版最大只到「血厚、攻高、掉落好」
- ❌ 新美术：怪继续用 `PlaceholderArt` 按 id 取色的占位图

## 验收

- `bash Tools/run-all-checks.sh` 全绿（无头 Domain 自检 + 四层编译）
- `python3 Tools/gen_monsters.py` / `gen_items.py` / `gen_maps.py` 三个校验全过
- Unity 菜单 ④ 冒烟自检全绿（含新的怪与刷怪区校验）
- 肉眼可验：草原西北打得动、东北和洞窟深处打不动；远程怪隔着石墙不打你，拐角一露头就打；
  打一只狼会被一群狼追
