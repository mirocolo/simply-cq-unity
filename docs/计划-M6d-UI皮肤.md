# M6d 计划 —— UI 皮肤（M6 收尾）

## 这一版做什么

M6 的最后一块。现在的问题不是"面板不好看"，而是**五个界面各自画各自的**：

| 文件 | 自己复制了一套 |
| --- | --- |
| `InventoryUi` / `ShopUi` / `TeleportUi` / `TuningPanel` / `SkillBarUi` | 各有一份 `Fill` / `Border` / `LRect` / `EnsureStyles` / 各自写死的颜色 |

后果是：改一个配色要动五个文件，改完还容易漏（面板边框就有 3 种不同的金色）。
所以这一版的重点是**把皮肤收成一个模块**，顺手把观感往"传奇那套暗底金边"上收。

### 交付

- `UiSkin.cs` —— 唯一的皮肤来源：
  - 一套配色（暗底 / 金边 / 标题金 / 正文 / 次要 / 强调 / 危险 / 血蓝经验）
  - 一套字号（共用 `UiScale`，**按当前缩放缓存**，DPI 变了自动重建）
  - `Panel`（背景 + 金边 + 标题栏）、`Row`（列表行，悬停高亮）、`Bar`（**分段**血条/经验条）
  - `Fill` / `Border` / `LRect` 这些画图小工具
- **五个面板全部改成读 `UiSkin`**，各自那份删掉（净代码量应该是减少的）
- **面板可拖动**：`PanelDrag` —— 在标题栏按住就能拖，位置在本次运行内保留
- 观感往类传奇靠：
  - 面板：暗石底 + 双线金边 + 分隔的标题栏
  - 血条 / 蓝条 / 经验条：**分段刻度**（传奇那种一格一格的血条），数字压在条上
  - 快捷栏：统一用同一套底色与金边，冷却遮罩更明确
- 自检：`UiSkin` 的样式能建起来、配色合法、分段条在 0% / 100% / 越界时不炸、
  拖动能真的移动面板、**拖动不会跑到屏幕外**（拖出边界要夹回来）

## 这一版**不做**

- ❌ 换 UGUI / UI Toolkit：仍然是 IMGUI（零资源、零 prefab，这个性质继续保留）
- ❌ 换美术素材（地表/角色仍是代码画）
- ❌ 拖拽物品 / 背包格互换（那是交互，不是皮肤）
- ❌ 背景音乐
- ❌ 图鉴/任务/组队这类新面板

## 一处必要的取舍

拖动会让"面板位置"变成状态，而面板现在是用常量算位置、**每帧重算**的（所以没有状态、不会漂）。
引入拖动后必须把偏移量存起来（`PanelDrag.Offset`），并且：
- 偏移只在**本次运行内**有效（不写盘）—— 皮肤不该顺带做"记住布局"
- 拖动结束后不改变面板大小，也不影响"鼠标在面板上就不挥刀"这条判断（判断用的是移动后的矩形）

## 验收

- `bash Tools/run-all-checks.sh` 全绿
- Unity 批处理：冒烟自检 + 数值审计一起跑，失败项 0
- 五个面板里**不再有各自复制的 `Fill` / `Border` / `EnsureStyles`**（grep 一遍确认）
- 肉眼可验：面板长得一样了、边框和标题统一、血条有分段刻度、五个面板都能拖、拖不出屏幕
