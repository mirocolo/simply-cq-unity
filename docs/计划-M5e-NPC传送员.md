# M5e 计划 —— NPC 传送员（M5 最后一块）

## 这一版做什么

补上 M5 里写的「NPC 与传送」的 NPC 那半边：站到传送员旁边按 `E`，弹出目的地菜单，点一个就过去。

和「踩传送点」是两套并存的东西，各有用处：

| | 踩传送点（M5 第一步） | 传送员（这一版） |
| --- | --- | --- |
| 触发 | 走进那一格 | 站在 NPC 旁按 `E` 选目的地 |
| 适合 | 相邻两张图之间走 | 从镇子直接跳去远处的洞窟 |
| 落点 | 数据里写死 | 数据里写死 + 路费 |

### 交付

- `NpcDef` 加 `Teleports`（`targetMap / 目标坐标 / 显示名 / 路费`），
  `npcs.json` 里加一条就多一个可去的地方 —— **不用碰代码**
- `IntentKind.TeleportTo` + `TeleportSystem`：交互距离、路费、目的地校验、`World.ChangeMap`
- 一个 NPC 可以只会卖货、只会传送、或者两样都会；`E` 键按**身边这个 NPC 会什么**决定开哪个面板
- `TeleportUi`：目的地列表 + 路费（钱不够标红）+ NPC 台词；走过去自动关，传送成功后也自动关
- 拒绝全部有可见反馈：附近没传送员 / 路费不够 / 目的地地图不存在（复用 `PortalRefused` 事件，界面和飘字共用一套处理）
- 复用 `World.ChangeMap`，所以**同图传送只挪人、跨图传送才清怪**，和踩传送点走的是同一条路
- 数据自检：目的地地图存在、落点可走、落点不是传送点、传送员边上至少有一格站得住

## 这一版**不做**

- ❌ 传送动画 / 特效 / 音效（M6）
- ❌ 传送要读条 / 被打断
- ❌ 按等级或任务解锁目的地（现在只有路费这一道门槛）
- ❌ 把装备或怪继续往上铺（M5 那两块已经收尾）

## 验收

- `bash Tools/run-all-checks.sh` 全绿（无头 Domain 自检 + 四层编译）
- Unity 菜单 ④ 冒烟自检全绿（含传送员目的地校验 + 一次真实传送）
- 肉眼可验：比邻镇广场东侧站着传送员，按 `E` 弹菜单，能免费回草原、花 30 金去洞窟；
  金币不够时那一行是红的，点了会告诉你为什么
