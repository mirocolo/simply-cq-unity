# 优化建议清单 —— 以「页游传奇的挂机爽感」为主线（2026-09 · M6 收尾后）

> 需求原话：**"给我单机传奇带来页游传奇的挂机爽感"**。
> 这份清单围绕它重排：P0 全部是挂机爽感的直接组成，P1 是撑住挂机体验的配套，
> P2 之后才是内容扩张与工程项。每条都先核实过代码现状再提改法。
>
> 成本标记：**小** = 半天内 / **中** = 一两天 / **大** = 一周以上。

---

## 先说一个架构上的好消息

页游挂机的本质是「**输入变成可选的**」。这个项目的 Domain 是纯 Intent 驱动的：
玩家走路、攻击、放技能全部通过 `_intents` 列表进入模拟，怪物走 `AiSystem`。
所以**挂机 AI 不需要碰任何玩法逻辑**——它只是一个"替玩家往 `_intents` 里写东西"的组件，
和手操共存：你按了键就以你为准，没按就挂机接管。拾取更是现成的（踩格子自动捡）。
这意味着挂机系统可以做到"随时开、随时关、绝不和手操打架"，而且是纯表现层+输入层的活，
Domain 的 254 项无头自检完全不受影响。

## P0 · 挂机爽感核心（页游体验的骨架）

### 1. 自动战斗（挂机 AI）—— 成本：中 · **整条主线的地基**

**现状**：一切手操。按住空格普攻、按 1-3 放技能、WASD 走位。

**建议**：`AutoPilot` 组件——开关（`T` 键或屏幕大按钮）打开后，每 tick 产出玩家意图：
选最近/残血的怪 → 走进射程 → 按攻击间隔普攻 → 技能好了就放（MP 够才放）→ 周围没怪就走向
最近的刷怪区。逻辑直接抄 `AiSystem` 的目标选择（同套路：Nearest、视线、 leash）。
**页游的灵魂就在这**：人可以离开屏幕，角色自己打怪捡东西，回来看一背包的收获。
危险保护：HP < 30% 自动停手（或接第 2 条自动喝药）。

### 2. 自动喝药 —— 成本：小

**现状**：药水在售、`ItemUsed` 事件和音效齐全，但战斗中喝药要开背包点——挂机模式下根本喝不上。

**建议**：HP 低于 50% 自动喝最便宜的血药，MP 低于 30% 自动喝蓝药（阈值进 `F1` 调参面板）。
手动键也顺手给：`Q` 喝血。有了这条，挂机才能"通宵"，也才需要第 7 条的耐久来制造回头率。

### 3. 战力值（一个数字）—— 成本：小

**现状**：角色面板有攻/防/血/攻速，但没有一个**能看着往上涨的单一数字**。页游的第一爽点
就是"战力 +2,437"的飘字。

**建议**：`战力 = 中值攻击×3 + 防御×2 + 最大血×0.5`（权重进调参面板）。角色面板顶部大字显示；
换装/升级时在人物头顶飘"战力 ↑386"。计算纯读 `StatCalculator` 的结果，半天的事。

### 4. 收益统计面板 —— 成本：小

**现状**：杀了多少怪、赚了多少钱、爆了几件紫，全部**事后无感**。页游挂机每隔一会儿就给你
一张"收益报告"，这是让人愿意继续挂的心理引擎。

**建议**：挂机开启时显示悬浮小面板：本次挂机 时长 / 击杀 / 经验 / 金币 / 装备（按品质计数），
"效率"一行（击杀/分钟、金币/分钟——**数值审计已经算过每只怪的效率，公式直接复用**）。
关游戏再开，报告还在（存进存档）。

### 5. 升级爆发感 —— 成本：小

**现状**：升级有金色光柱 + 环 + 小乐句，但它是"哦，升级了"的量级。页游的升级是**事件**：
全屏闪、冲击波、回满血蓝。

**建议**：升级时①血蓝全满（战斗中心理价值巨大）②全屏白闪 0.15s + 更大范围的环形冲击波
③"LEVEL UP!"大字居中弹出。全部用现有 `FxKind.Beam/Ring` + `FloatingText` 拼装，无新资源。

### 6. 掉落通知流 —— 成本：小

**现状**：蓝装以上有光柱（隔着半个屏幕能看见），但**捡到了什么没有主动告诉你**。
页游的"恭喜获得 XXX"推送流是持续正反馈的来源。

**建议**：屏幕右下角一条**拾取通知流**（最多留 5 条，旧的往上顶淡出）：
白/绿装不推（噪音），蓝起才推，紫装整条变紫 + 配一个专属音效（现有 jingle 里挑一个升调的）。
金币连捡合并显示"金币 +128"。

### 7. 离线收益 —— 成本：中 · 挂机爽感的最后一环

**现状**：关游戏=收益归零。页游的"睡觉也在变强"是留存核弹。

**建议**：读档时算离线时长（封顶 8 小时），按**当前地图的审计效率**折算收益：
`击杀 = 离线秒 × 击杀/秒`，经验金币按表发放，装备按掉率摇 3~5 件（蓝以上概率打折，离线不白给紫）。
上线弹一张"欢迎回来"结算面板。防作弊对单机无所谓，重点是公式要复用审计的
`ExpPerSecond/GoldPerSecond`，别另写一套。

## P1 · 撑住挂机体验的配套（没有它们，挂机挂不长久）

### 8. 耐久与修理 —— 成本：中

挂机把打怪变成印钞机之后，**必须有出水口**，否则金币无限膨胀、装备永动机。
耐久 = 命中/受击按百分比掉，归零属性减半（不碎）；杂货商"修理全部"按总价值计价；
挂机面板加"自动修理"开关（回城自动修）。`ItemInstance` 加 `Durability`，
存档 `Version2 → Version3`（版本迁移框架已有）。这条让挂机有了**节奏**：挂一阵 → 回城修/卖 → 再挂。

### 9. 自动卖白绿 —— 成本：小

挂机一晚背包必满。背包满后自动把白/绿装卖给系统（按商店回收价，蓝紫永远留），
开关在挂机面板上。和第 8 条配合，挂机循环就完全闭合了：**出门挂机 → 回城修理+清包 → 再出发**。

### 10. 仓库 NPC —— 成本：中

挂机产出的蓝紫装备很快超过 48 格背包。镇上仓库 NPC（复用商人 `E` 分流），按等级段分页；
存取走 Intent，Domain 加一个 `Stash` 容器（`Inventory` 的复用），进存档。

### 11. 战斗音乐 —— 成本：小～中

挂机时一首循环曲放 20 分钟会疯。素材包里 **Boss Fight 那首一直没用**（CC0）：
玩家 `LastDamagedTick` 在近 N tick 内 → 切战斗曲，脱战 5 秒淡回地图曲。
`MusicDirector` 的交叉淡入淡出现成，纯扩展。

### 12. 物品对比 tooltip —— 成本：小

挂机爆装多了，换装决策全靠心算。tooltip 对应属性后面加 `(+3)/(-2)` 绿红标。
数据全部现成，纯 `InventoryUi` 改动。

### 13. 死亡惩罚（挂机版）—— 成本：小

原建议"掉经验"在挂机语境下要修正：挂机死了应该**自动回城 + 停止挂机**（而不是继续送死）。
掉一半当前等级未消耗经验保留，作为"挂机不是无脑挂"的代价。复活保护 3 秒。

## P3 · 工程（都不是当前瓶颈，记录在案）

- **IMGUI 每帧字符串 GC**（~2KB/帧，6 处）：缓存+脏标记。等 GC spike 出现再做。
- **音频体积 5.5MB**：BGM 压 96kbps、音效 64kbps 可砍半。要分发时再做。
- **性能总评**：48x48 地图 + 可见剔除 + 特效池化 + tick 上限，**没有已知性能问题；不建议现在优化**。
- README「没有背景音乐」过期条目已顺手修正。

## 建议的落地顺序

```
第 1 周   #1 自动战斗 + #2 自动喝药 + #5 升级爆发        ← 挂机骨架立起来，当天就能挂
第 2 周   #3 战力值 + #4 收益统计 + #6 掉落通知流          ← 爽感可视化
第 3 周   #7 离线收益 + #8 耐久修理 + #9 自动卖白绿        ← 循环闭合，有节奏地挂
第 4 周   #10 仓库 + #11 战斗音乐 + #12 对比 + #13 死亡    ← 配套补齐
之后      P2 按兴趣扩张
```

**核心判断**：这个游戏的手操循环（打怪-爆装-换装）已经完整且被审计验证；
页游挂机爽感的本质是**把这套循环从"要我按"变成"替我转，我只看结果"**——
而 Intent 架构让这件事的成本低得反常（自动战斗≈把怪物 AI 抄给玩家）。
所以 P0 七条全是骨架级收益，先做它们。
