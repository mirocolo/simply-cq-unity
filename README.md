## 🌟 游戏亮点与核心特色

- ⚡ **自研 2.5D Isometric 视锥剔除渲染引擎**：
  - 纯代码矢量渲染，零外置图片资产，体积小于 1MB，秒开即玩！
  - 60FPS+ 丝滑运行，亚像素平滑相机跟随，告别画面抖动。
  - 霸气战士天魔金鳞神甲、昂扬外倾持刃姿态、百妖精美立绘、通天光柱大爆！
- ⚔️ **深度战斗体系与数值再平衡**：
  - **运9极境**：祝福油（+1~+7）、超级祝福油与罗刹神水，达成运9刀刀上限 MaxDC 极致爆发；运10激活神圣破甲！
  - **急速溢出质变**：攻速溢出转化为三阶残影连击、技能冷却缩减 (CDR 最高40%) 与风雷真伤。
  - **防猝死保护**：物理护甲吸收最高 70% 伤害，底层强制单次受击伤害不超最大 HP 的 35%，彻底杜绝被 Boss 秒杀。
  - **护体神盾与回蓝闭环**：神盾常驻 15% 免伤/护盾与每秒回蓝，普攻命中吸蓝，彻底解决技能卡手断蓝。
- 👹 **史诗首领攻坚**：
  - 沃玛教主、祖玛教主、赤月恶魔、黄泉教主、魔龙教主直至混元鸿蒙天尊（最高 2800 万生命值），沉浸式 30s~75s 首领战！
- 💎 **神装词缀与黑市经济**：
  - 装备掉落随机生成 1~3 条彩色词缀（吸血、吸蓝、增伤、急速等），支持乾坤洗炼石重铸。
  - 特戒神器（麻痹、护身、复活、隐身、贪婪）。
  - 按 `P` 打开神秘黑市商店，金币良性内循环。
- 🤖 **智能挂机与百妖图鉴**：
  - 启发式 A* 智能寻路，危险威胁评估与保命神盾释放，全自动战利品拾取与回收。
  - 百妖图鉴大字高对比度排版，阶梯位面检索，一键领悟真解与全局属性加成。

## 🛠️ 技术栈与工程架构

- **前端核心**：Vue 3.5 (Composition API), TypeScript 5.7, Vite 6, Tailwind CSS 3.4
- **架构解耦**：`GameWorld` 与 Vue 响应式彻底解耦 (`markRaw` + `shallowRef`)，消除 Proxy 性能开销。
- **UI 响应流**：顶层 `uiTick` 心跳版本号局部按需更新，兼顾原生高效 100ms 逻辑主循环与毫秒级精确 UI 渲染。
- **音效系统**：Web Audio API 纯合成打击、烈火、升级音效，零音频文件依赖。

## 🚀 快速上手与本地开发

### 1. 安装依赖
```bash
pnpm install
# 或 npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
# 浏览器访问 http://localhost:5173/
```

### 3. 构建生产包与类型检查
```bash
npm run build
```

### 4. 运行端到端自动化测试套件
```bash
# 战斗数值与核心机制综合测试
./node_modules/.bin/jiti scripts/test_combat_and_haste_rebalance.ts

# 经验与图鉴响应式测试
./node_modules/.bin/jiti scripts/test_exp_and_codex_reactivity.ts

# 一键领取与强化继承测试
./node_modules/.bin/jiti scripts/test_onekey_claim_and_enhance.ts
```
