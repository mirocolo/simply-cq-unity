# simply-cq-unity

《传奇》风格的 **本地单机** 复刻 —— Unity 6 + 纯 C# 逻辑层。

> 目标不是还原原版，而是把「打怪 → 爆装 → 回城卖 → 换装变强」这条循环做得**手感像传奇**。
> 完整方案见 `docs/设计方案.md`。

---

## 现在能跑什么（M0 ~ M5 完成，M6 进行中）

**世界（M1）**

- 一张 48×48 的「新手草原」：树林、水塘、十字土路、山坡，**斜俯视伪 2.5D** 投影
- WASD / 方向键 **8 方向格子走路**，一格一格，撞墙撞怪会原地转身
- 相机平滑跟随 + 地图边界夹取
- 刷怪区维持着一批怪：**被动怪（鸡 / 野兔 / 鹿）** 在出生点附近游荡；**主动怪** 看见你会用 **A\*** 绕过障碍追你，追出一定距离会脱战回家（怪的种类与分布见下面 M5d）
- 刷怪区自动维持怪物数量，死了会补刷

**战斗与成长（M2）**

- **近战攻击**：空格 / J / 鼠标左键，只打「面向那一侧」，不做背刺；攻击有间隔（`playerAttackInterval` tick）
- **命中 / 暴击 / 护甲** 全套结算，伤害公式全在 `balance.json` 里可调
- **死亡**：怪会留尸体（可配时长）→ 清掉 → 释放格子；击杀者拿经验
- **升级**：经验曲线 `base * Lv^pow`，升级加血量/攻击/防御并回满血
- **掉落**：金币掉在死亡点上，走上去**自动拾取**，飘 `+5 金币`
- **飘字**：伤害数字 / 暴击 / MISS / 挥空 / 升级 / 你死了
- **受击反馈**：中招闪红 + 轻微弹一下；尸体半透明
- **脱战回血**：60 tick 没挨打就开始自动恢复
- **玩家死亡 → 40 tick 后回出生点满血复活**，死亡期间无法移动和攻击
- **HUD**：HP 条 + 经验条 + 等级 / 金币 / 攻防
- 逻辑层 **254 项自动化自检**，而且**不需要打开 Unity** 就能跑

**物品与成长（M3，逻辑 + 界面 + 商店 + 存档都已完成）**

- **背包 48 格**：只有格子会限制你（捡不下了就留在原地，并给一次提示，2 秒节流不刷屏）。**负重机制已按需求移除** —— `items.json` 里不再有重量字段
- **装备 8 个部位**：武器 / 衣服 / 头盔 / 项链 / 手镯 / 戒指 / 腰带 / 靴子
- **属性聚合**：有效属性 = 基础属性 + 装备加成；升级改的是基础值，不会被换装覆盖
- **穿脱安全**：背包满时换装会失败，但**装备不会凭空消失**（有专门用例守着）
- **掉落表**：每只怪一套「掉什么 / 多少几率 / 掉几个」，多件掉落散落在附近格子，不会互相覆盖
- **消耗品**：金创药回血、魔法药回蓝；满血时不浪费
- **新手包**：进游戏背包里就有木剑 / 布衣 / 草鞋 / 3 瓶金创药
- **背包 / 角色面板**：`I` 开关背包、`C` 开关角色；48 格网格、悬停看属性、左键穿戴使用、右键丢弃、点装备栏卸下
- **地面掉落物带名字**：站到附近就显示名称，按类型上色（装备蓝 / 金币金 / 药水绿 / 材料灰），不用捡起来才知道掉了什么
- **属性面板看得懂**：血条 + 经验条；每条属性都给 {@基础 / 装备@} 明细，换装有没有用一眼看得出
- **UI 按 DPI 等比缩放**：基准 1080 高，Retina 屏（back buffer 3456×2160）自动放大 2 倍，字不会小到看不清
- **商店 NPC**：地图上有杂货商，站到旁边按 `E` 开关；左栏买（余额不足标红）、右栏点一下卖（回收价 = 原价 × 0.4）
- **存档**：`F5` 存 / `F9` 读 / `Esc` 退出自动存；进游戏自动读档。只存玩家（属性/位置/背包/装备），怪和掉落物重进重新生成
- **任何拒绝都有可见反馈**：金币不够 / 背包满了 / 附近没商人 / 捡不起来 / 技能冷却中，都会明确告诉你原因

**战士技能（M4，只做战士）**

- **普攻有动作了**：每次挥砍都会朝面向方向前冲一下 + 一道旋转刀光（之前扣了血但屏幕上什么都没发生）
- **攻速看得见**：按住攻击键持续出手，按 @@AttackInterval@@ 节流；角色面板显示 @@1.4 次/秒 / 间隔 7 tick@@
- **4 个技能**（按等级自动学会，技能书留到以后）：
  | 技能 | 学会等级 | 效果 |
  | --- | --- | --- |
  | 基本剑术 | 1 | 被动：命中 +3，攻击 +1 |
  | 攻杀剑术 | 1 | 身前单体，220% 伤害，3 蓝，1.8 秒冷却 |
  | 刺杀剑术 | 3 | 身前两格直线，150%，5 蓝 |
  | 烈火剑法 | 6 | 自身周围范围斩，180%，9 蓝 |
- **底部快捷栏**：显示技能名 / 蓝耗 / 冷却倒计时，冷却中会盖一层遮罩并显示剩余秒数

**多地图与传送（M5 第一步）**

- **三张图连成一条线**：新手草原 → 比邻镇（安全区）→ 幽暗石洞。`map_grassland.json` 里那条指向 `map_town` 的传送点从 M0 就写在数据里，这一步终于把它接上了
- **走到传送点上就换图**，不用按键 —— 传奇就是这么走的
- **换图是「走进」而不是「站在」**：落地那一格就算本身也是传送点，也不会被弹回去；读档/复活这种外部摆位也不会误触发
- **换图不重建世界**：旧图的怪、掉落物、飘字、刀光全部清干净，新图的怪自动开刷，角色等级/背包/装备/金币原样带过去
- **相机瞬移**：换图不会「从上一张图一路飘过去」，同时立刻换成新图的边界夹取
- **存档记地图**：`F5` 存在洞窟里，`F9` 会把你送回洞窟（存档里的 `MapId` 以前只是写了没用）
- **数据自检**：传送目标图存不存在、落点可不可走、落点是不是另一个传送点（会来回弹）、刷怪区有没有可站格 —— 全部在冒烟自检里算一遍
- 逻辑层 **254 项自动化自检**，而且**不需要打开 Unity** 就能跑

**装备品质（M5 第二步）**

- **白 / 绿 / 蓝 / 紫 四档品质**，而且品质是**掉落那一刻摇出来的**，不是写死在物品表里 ——
  同一把木剑，白板出货就是白板，爆出史诗就是史诗。这是「同一件装备有人卖 100、有人卖 1000」的来源
- **品质真的有用**，不是只改个颜色：
  | 品质 | 名字颜色 | 装备属性 | 买入价 |
  | --- | --- | --- | --- |
  | 普通 | 白 | ×1.00 | ×1.0 |
  | 精良 | 绿 | ×1.25 | ×1.6 |
  | 稀有 | 蓝 | ×1.55 | ×2.6 |
  | 史诗 | 紫 | ×1.90 | ×4.2 |
- **怪越高级越容易出好货**：品质权重按怪的等级往上抬（白装不吃加成），系数在 `balance.json` 的 `loot` 段里
- **品质在哪儿都看得见**：背包格子左边一条品质色带、鼠标提示标题按品质上色、角色面板的装备栏、地面掉落物的名字、
  捡起来那一下的飘字（捡到史诗会飘一条紫字，不用翻背包就知道爆了好东西）
- **面板说的就是实际生效的**：鼠标提示里的攻击/防御/生命是**按这一件的品质算过**的，和穿上之后的属性完全对得上
  （顺手修了一个老 bug：提示里的"售价"以前写死 `原价 ÷ 2`，和商店实际的 `×0.4` 对不上）
- **商店只卖白装和精良货**：稀有/史诗只能打怪爆 —— 爆装才有意义
- **穿脱 / 换装 / 丢弃 / 买卖 / 跨图 / 存档都不会弄丢品质**：`F5` 存的史诗，`F9` 读回来还是史诗
- **存档升到 v2**：v1 的旧档照样能读，品质一律按白色处理，不丢东西
- **物品表可以写品质下限**：`"minQuality": "green"` 表示这件装备最低也是精良（长剑、青铜甲已经这么配了）

**60 件装备（M5 第三步）**

- **装备从 13 件铺到 60 件**：8 个部位 × 3 个等级段（**Lv1 / Lv4 / Lv7**）× 2~3 个档次
- **等级段跟怪走**：鸡(1) 只出 Lv1 段、野狼(4) 只出 Lv4 段、野猪(6) 只出 Lv7 段 ——
  幽暗石洞里野狼野猪的刷怪区最多，所以**越往深处打越出好东西**，不用另加"地图等级"机制
- **同段内分档次**：普通款（品质下限白）/ 上品款（下限绿，如「精铁剑」）/ 珍品款（下限蓝，如「黑铁剑」）。
  档次越高**白装基础属性也越高** —— 不是只靠摇品质
- **强度曲线照着老数据标定**：Lv1 木剑还是 2-4，Lv7 长剑 7-10 ——
  铺 60 件的过程顺手把数值放大两倍，是最容易犯又最难发现的错，所以曲线在脚本里写死并校验
- **每件都有出处**：60 件全部挂在怪的掉落表上；商店卖的是 Lv1 段的白装与精良货（**不卖稀有/史诗**）
- **商店按 minQuality 卖**：写了下限的货，买到手就是那个品质、收的也是那个价（不会"表里说精良、商店卖白板"）
- **不手写 JSON**：`python3 Tools/gen_items.py` 生成 + 校验（不带 `--write` 只校验并打印）。
  它把 ItemCatalog 的解析规则和 Domain 的硬约束各实现一遍：
  **部位断档、同档次越高级越强越贵、同段内品质阶梯不倒挂、每件有出处、怪的等级配得上掉的装备、
  爆装期望概率不失控** —— 这些手写 60 条数据最容易犯、又只有玩到中期才发现的错

**20 种怪（M5 第四步）**

- **怪从 3 种铺到 20 种**，Lv1 ~ Lv15，按等级带分到两张战斗图（比邻镇是安全区，不刷怪）
- **越往深处越危险**：草原 Lv1~6（西北林地最安全，往东/南逐渐加码），
  洞窟 Lv3~15（入口是蝙蝠，洞底是洞窟领主）。不用另加"地图等级"机制 —— 怪的等级就是地图的难度
- **洞窟加了一层「洞底大厅」**：Lv10~15 的怪有自己的窝，不是和入口的怪挤在一个厅里
- **远程怪**（石像鬼 / 幽魂 / 巫妖 / 幼龙）：`attackRange` 2~5，**而且必须看得见才出手** ——
  加了视线判定，不会隔着石墙射你，拐角一露头就打
- **群居怪**（野狼 / 骷髅 / 僵尸 / 野猪 / 半兽人 / 食尸鬼 / 狼王 / 暗黑骑士）：
  打其中任何一只，半径内的同类一起扑上来。一击秒杀也会惊动 —— 倒下的那只不会把同伴的耳朵带走
- **每只怪一套掉落表**：按等级带引用那 60 件装备，每件装备仍然都打得到
- **不手写 JSON**：`python3 Tools/gen_monsters.py` 生成 + 校验。它把怪的等级带、AI 花样、
  掉落引用、刷怪区布局和难度分层全算一遍：
  **视野比射程还短、等级更高却更弱、没有刷怪区的怪、草原刷出 Lv7+ 的怪、往安全区塞刷怪区** ——
  都是手写 20 条数据最容易犯、又要玩到中期才发现的错

**NPC 传送员（M5 第五步 · M5 收尾）**

- **比邻镇广场东侧站着传送员**：站到旁边按 `E` 弹出目的地菜单，点一个就走 —— 传奇的传送员就是这么用的
- **和踩传送点并存**，各管各的：相邻两张图之间靠走（走进那一格就换图），从镇子跳去远处的洞窟靠传送员
- **目的地写在 `npcs.json` 里**：加一条就多一个可去的地方，不用碰代码。现在能免费回新手草原、花 30 金下洞窟
- **一个 NPC 可以只会卖货、只会传送、或者两样都会**：`E` 键按身边这个 NPC 会什么决定开哪个面板
- **同图传送只挪人、跨图传送才清怪**：走的是 `World.ChangeMap` 这一条路，和踩传送点规则完全一致
- **拒绝都有可见反馈**：附近没传送员 / 路费不够 / 目的地地图不存在，都会明说原因；成功时菜单自动关
- **数据自检**：目的地地图存在、落点可走、落点不是传送点（否则一到就被弹回去）、传送员边上至少有一格站得住

**音效（M6 第一步）**

- **34 条真音效**，覆盖：挥砍 / 挥空 / 命中 / 暴击 / 怪死 / 玩家死 / 复活 / 升级 / 学技能 / 放技能 /
  金币 / 拾取 / 穿装备 / 喝药 / 各类拒绝 / 面板开关 / 传送 / 脚步
- **零原创、零侵权**：全部是 Kenney 以 **CC0** 发布的免费素材（可商用可改可再分发，署名非必需）。
  仓库里只放了游戏用到的 34 个文件（416 KB），不是整包；来源与许可见
  `Assets/Resources/Audio/LICENSE.md`，重新拉取/换素材用 `Tools/vendor_audio.py`
- **有声像和远近**：屏幕右边的怪声音偏右，远处的打斗声变小 —— 2D 游戏不做真 3D 衰减，只算这两个，反而更清楚
- **按品质变调**：捡到史诗时音高比白装高，不用翻背包就听得出"这把是好东西"
- **按地面变脚步**：草原踩草、镇子和洞窟踩石头（`GameMap.IsHardGround` 判的，以后加新图不用改音效代码）
- **防刷屏**：每条音效有最短间隔，同一瞬间连发两次只响一次；12 路音源轮转，不会排队到"延迟半秒才响"
- **装备接上事件就出声**：音效是纯表现层，只订阅 Domain 事件 —— 所以 Domain 依然一行 UnityEngine 都没有
- **`M` 静音、`-` / `=` 调音量**，HUD 上直接显示当前音量
- **接线是可测的**：冒烟自检里逐条发事件，断言"发一次响一次"（18 类事件），
  并且检查表里引用的每个音频文件都真的能从 Resources 加载到 —— 手滑写错路径会立刻被抓出来

**战斗特效（M6 第二步）**

- **打起来终于"看得见"了**：之前只有普攻刀光，命中、暴击、死亡、升级在屏幕上都没反应
- **命中爆点**（星芒）/ **暴击**（更大的金橙色爆点 + 冲击波环 + **镜头震动**）/
  **自己挨打**（红环 + 震动，比打在怪身上更需要被感觉到）/ **死亡烟尘**（怪是灰褐色，玩家是暗红色）/
  **升级金色光柱** + 扩散环 / **复活蓝色光柱**
- **三个技能三种样子**：攻杀剑术 = 更大的斩击，刺杀剑术 = 身前两格的直线斩，烈火剑法 = 自身周围一圈火 ——
  不然放了技能只看得出"扣了蓝"
- **掉落光柱**：地面上的**蓝装以上**会立一道品质色光柱，一直立到被捡走 ——
  名字颜色要凑近才看得到，光柱隔着半个屏幕就能看见，这就是"看光柱就知道爆了什么"
- **镜头震动**做对了：平滑位置和抖动偏移分开存，抖动只加在最终位置上 —— 把抖动喂回平滑，相机会慢慢漂走
- **依然是零素材**：6 种图形（星芒/扩散环/烟团/光柱/直线斩/刀光）都由 `PlaceholderArt` 运行时生成，
  特效池只负责染色 —— 一张白图复用成命中、暴击、升级、品质光柱各种颜色
- **池化复用**：命中每刀都有，每次 new GameObject 会一直产生 GC 垃圾；现在连着打 200 下池子也只建 8 个物体

**数值审计 + 手感调参（M6 第三步）**

- **先说问题**：20 种怪和 60 件装备的数值都是按公式推出来的，**公式自洽不等于曲线能玩**。
  审计第一次跑出来就发现「同级玩家防 28、野狼攻 3-6」—— 整条中低段**完全无伤**，
  而且同级怪 3 刀就死。这不是能靠看 JSON 发现的问题。
- **数值审计**（菜单 `SimplyCQ / ⑥`，批处理里和冒烟自检一起跑、一起算失败项）：
  用**游戏里那个伤害公式**模拟战斗，打印每只怪的 TTK / 要砍几刀 / 玩家承伤 / 能连打几只，
  并断言：每只怪都打得死、同级不会被一刀秒、同级至少能连打 3 只、越高级打得越久、
  越级更吃力/压级更轻松、换装提升 ≥1.5 倍、Lv1→15 不是天文数字、传送费不是负担
- **照着审计结果把怪重做了一遍**（同一只野狼）：

  | | 击杀耗时 | 玩家承伤 | 能连打 |
  | --- | --- | --- | --- |
  | 改前 | 2.5s | 0（完全无伤） | 99 只 |
  | 改后 | 8.1s | 23（约 10% 血） | 10 只 |

  精英和头目再往上加码：狼王 12.9s / 掉 110 血 / 只能连打 3 只，洞窟领主 28.9s / 掉 320 血 / 1 只
- **怪的档次进了数据**（`trash / squishy / normal / tanky / elite / boss`）：
  普通怪必须严格随等级变强，精英和头目**故意**破格 —— 它们单独校验「比同级普通怪更耐打」

  - 为什么能立刻生效：`CombatTuning` / `ShopTuning` / `LootTuning` 都是引用类型，系统每 tick 现读字段
  - 「怪的整体倍率」是关键：20 种怪 × 5 个数值不可能一件件手调，有这组总倍率才能"整体偏硬"一键修正

## 代码结构

```
Assets/
├── Scripts/
│   ├── Domain/          # 纯 C#，asmdef 里 noEngineReferences=true，禁止 using UnityEngine
│   │   ├── Core/        #   TilePos / Dir / Rng / EntityId / Entity / Intent / Events
│   │   ├── Map/         #   GameMap（通行表 / 传送点 / 刷怪区）
│   │   ├── World/       #   World / EventBus / PathFinder / LineOfSight / ISystem
│   │   ├── Systems/     #   MovementSystem / AiSystem / SpawnerSystem
│   │   └── Simulation.cs
│   ├── Data/            # JSON DTO + 加载（唯一用 JsonUtility 的地方）
│   ├── Unity/           # 视图 / 输入 / 组装：唯一允许碰 UnityEngine 的业务层
│   │   ├── View/        #   Projection / PlaceholderArt / TileViewPool / EntityViewRegistry / CameraRig
│   │   │                #   CombatFxPool（特效池）/ LootBeamOverlay（掉落光柱）/ FloatingTextOverlay
│   │   ├── Audio/       #   SfxTable（音效表）/ AudioDirector（事件 -> 声音 + 声像）
│   │   ├── UI/          #   背包/角色/商店/传送面板 + TuningPanel（F1 手感调参）
│   │   ├── Input/       #   PlayerInputSource
│   │   └── Bootstrap/   #   GameBootstrap（组装 + 固定 tick 循环 + 调试 HUD）
│   └── Editor/          # 一键搭场景 / 冒烟自检 / 数值审计（BalanceAudit）
├── Resources/Audio/     # 34 条 CC0 音效（Kenney）+ LICENSE.md；表在 SfxTable 里
└── StreamingAssets/Data/  # balance.json / items.json / monsters.json / npcs.json / skills.json / maps/*.json
```

### 一条铁律

**`Assets/Scripts/Domain` 里不允许出现 `using UnityEngine`。**
由 `SimplyCQ.Domain.asmdef` 的 `noEngineReferences: true` 强制保证，写错直接编译不过。

数据流是单向的：

```
输入 ──► Intent ──► Domain（固定 10Hz tick）──► 事件 ──► 视图 / UI / 音效
                                                    ▲
                                            表现层只读 World、只订阅事件
```

这么做的收益，现在就能看到三条：**能无头自检**、**存档只差序列化 World**、**以后要上服务端可以直接把 Domain 搬过去**。

  "level": 4, "hp": 70, "ac": 1, "minDc": 3, "maxDc": 6, "exp": 18,
  "moveSpeed": 4, "attackInterval": 10, "attackRange": 1,

### `Data/items.json` —— 物品与装备（60 件装备）

```json
{ "id": "wp_long", "name": "长剑", "sprite": "wp_long",
  "type": "equip", "slot": "weapon",
  "price": 840, "levelReq": 7, "minQuality": "green",
  "minDc": 7, "maxDc": 10, "desc": "好东西" }
```

`price` 填的是**白装价**（品质倍率在代码里乘）；`minDc` / `maxDc` 这些也是**白装数值**
（绿/蓝/紫按 1.25 / 1.55 / 1.9 倍放大）。`minQuality` 是掉落品质的**下限**，不填就是白装 ——
好东西想只从怪身上出，就配 `minQuality` 并且**别放进 npcs.json 的 stock**（商店只卖白装和精良货，自检会守着这条）。

**这 60 件不要手改**，改 `Tools/gen_items.py` 里的设计表再跑一次（掉落表在 `monsters.json`，归 `gen_monsters.py` 管）：

```bash
python3 Tools/gen_items.py            # 只校验并打印阶梯，不落盘
python3 Tools/gen_items.py --write    # 写回 items.json
```

设计表是 `(id, 名字, 部位, 等级段, 档次)` 五列，数值全由 `BASE_POINTS × 等级^0.55 × 档次倍率` 推出来 ——
所以「越高级越强、越贵、品质下限越高」是**算出来的**，不是一件件手填的。
老 id（`wp_wood` / `ar_cloth` 那些）在脚本里有硬校验：改名等于把玩家的存档弄丢。

### `Data/monsters.json` —— 属性 / AI / 掉落

```json
{ "id": "mon_wolf", "name": "野狼", "sprite": "mon_wolf",
  "level": 4, "hp": 70, "ac": 1, "minDc": 3, "maxDc": 6, "exp": 18,
  "moveSpeed": 4, "attackInterval": 10, "attackRange": 1,
  "vision": 7, "aggressive": true, "leash": 14 }
```

`drops` 里的装备条目由 `Tools/gen_monsters.py` 生成（按等级段取装备、按档次摊概率）；
材料 / 药水那几条手写在生成器的 `KEPT_DROPS` 里。

**这 20 种怪也不要手改**（连同它们的掉落表）：

```bash
python3 Tools/gen_monsters.py            # 只校验并打印名单，不落盘
python3 Tools/gen_monsters.py --write    # 写回 monsters.json
```

它会拦住这些错：**视野比射程还短的远程怪、攻防上下限填反、等级更高却更弱、没有刷怪区的怪、
草原刷出 Lv7+ 的怪、往安全区（比邻镇）塞刷怪区**。
`packRadius` / `attackRange` 这类"表里配了但游戏里没生效"的坑，冒烟自检里也有专门用例盯着。

**刷怪区在 `Data/maps/*.json` 里**：`map_grassland.json` 手写，`map_town` / `map_cave` 由
`python3 Tools/gen_maps.py --write` 生成（它也会校验已有的草原图）。

{ "tickPerSecond": 10, "playerMoveSpeed": 3,

**调手感就看这几个**：`tickPerSecond`（逻辑频率）、`playerMoveSpeed`（走一格要几个 tick）、`monsters.json` 里的 `moveSpeed` / `attackInterval`。

## 已知限制

- **存档只有一个槽位**，而且只存玩家：怪物、地面掉落物、刷怪进度都不存（重进重新生成）
- **商店只有买卖**：还没有修理 / 耐久 / 仓库
- **传送员只有一个**（比邻镇）：从洞窟出来得走到入口的传送点；加传送员只要往 `npcs.json` 加一条 + 在地图上摆一个
- **传送没有读条 / 动画**：点了就到，也不会被打断（特效和手感是 M6）
- **面板是 IMGUI 画的**：能玩、零资源，但不是最终形态；换 UGUI / UI Toolkit 只需要替掉 `InventoryUi` 一个类
- **没有药水**：靠脱战回血和升级回满，所以现在偏"能打"而不是"传奇那种要囤药"
- 只有键盘 + 鼠标左键；新 Input System 没接（`PlayerInputSource` 里留了 `#if` 分支，切过去会打明确警告而不是崩）
- **装备阶梯到 Lv7 为止**：怪已经铺到 Lv15，但 Lv8+ 的怪掉的是 Lv7 那批（当前最好的）。
  想往上接只要给 `Tools/gen_items.py` 的设计表加一个等级段（`BANDS` + `TABLE`），掉落表会自动跟着走
- **远程怪没有投射物表现**：伤害是瞬间结算的，看不出"火球飞过去"；那是特效那块（M6）
- **BOSS 没有专属机制**：洞窟领主只是"血厚、攻高、掉得好"，没有狂暴 / 分身 / 阶段转换
- **远程怪的视线只判地形**：不判别的怪挡视线（怪之间互相遮挡既说不清也没必要）
- **商店不卖稀有/史诗**：这条是故意定的规矩（好东西靠打），自检会拦着；想卖就把货加进 `npcs.json` 的 `stock`
  并把 `minQuality` 降到 `green` 以内
- 只有三张图：`portals` 数据已就位，切图逻辑也做了；加图只要往 `Data/maps/` 丢 `map_*.json`
- **数值是审计出来的，不是玩出来的**：审计能保证「打得死、打得动、有压力、换装有意义」这些硬指标，
  但"爽不爽"还得人来玩。`F1` 就是为这个留的 —— 觉得哪里不对，当场调完导出
- **美术还是代码画的占位图**：音效已经是真素材了，特效也是代码画的；地表/角色/怪物仍是 `PlaceholderArt` 运行时生成
- **没有背景音乐**：这版只做音效；BGM 要循环、要混音、要按地图切换，是另一件事
- **不含任何原版素材**：音效是 Kenney 的 CC0 素材（见 `Assets/Resources/Audio/LICENSE.md`），
  美术是自己画的，没有原版的地图文件 / 名称 / LOGO
